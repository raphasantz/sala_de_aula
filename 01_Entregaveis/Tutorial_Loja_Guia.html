Passo 0 — O que vamos construir (visão geral)

Neste tutorial você coloca no ar, passo a passo, a Loja Tech da Turma: um site completo em HTML + CSS + PHP rodando no XAMPP, com banco MySQL e um gerencial em VB6 que compartilha o mesmo banco. Cada passo tem um “print” ilustrado, um bloco 🛠 TENTE VOCÊ e um ⚠ ERRO COMUM.

Mapa das páginas: index.php (vitrine) › produtos.php (catálogo com filtro) › produto.php?id=N (detalhe + foto) › pagamentos.php (Pix/cartão/boleto simulados) › processar_pedido.php (grava venda e baixa estoque) › contato.php (contato + localização) › cadastro.php (clientes).

C:\xampp\htdocs\loja\
├── index.php  produtos.php  produto.php
├── pagamentos.php  processar_pedido.php
├── contato.php  cadastro.php  processar_*.php
├── includes\  (conexao, cabecalho, rodape)
├── css\estilo.css
└── imagens\  (logo, banner, produtos, mapa, ícones)
✔ CHECKPré-requisitos: VS Code + XAMPP instalados (veja o Checklist_Downloads.pdf) e o ZIP Projeto_Loja_Tech_da_Turma extraído.

Passo 1 — Copiar o site para a casa do XAMPP

O XAMPP só executa PHP dentro da pasta htdocs. Copie a pasta site do ZIP para C:\xampp\htdocs\loja (pode arrastar pelo Explorador de Arquivos). Abra a pasta no VS Code (Arquivo › Abrir Pasta) para acompanhar os arquivos.

🛠 TENTE VOCÊAbra o VS Code em C:\xampp\htdocs\loja e confira na barra lateral as 7 páginas .php, a pasta includes/, css/ e imagens/ — igualzinho ao print.
⚠ ERRO COMUMDeixar as páginas fora da htdocs ou com nome .html: arquivo .html NÃO executa PHP (esse era o bug do “site sem fundo e sem imagem”).

Passo 2 — Ligar os servidores (Apache + MySQL)

Abra o Painel de Controle do XAMPP e clique em Start nas linhas Apache e MySQL. As duas precisam ficar verdes, com portas 80/443 e 3306.

🛠 TENTE VOCÊCom os dois verdes, abra no navegador: http://localhost — o painel do XAMPP confirma que o Apache está vivo.
⚠ ERRO COMUMApache não inicia (vermelho): porta 80 ocupada (Skype/IIS). Feche o programa ou mude a porta em Config › httpd.conf.

Passo 3 — Importar o banco loja_turma

No navegador: http://localhost/phpmyadmin › aba Importar › escolha o arquivo banco/loja_turma.sql do ZIP › Executar. Pronto: banco, 4 tabelas, dados de exemplo e a view de estoque baixo criados de uma vez.

cd C:\xampp\mysql\bin
mysql -u root < C:\caminho\banco\loja_turma.sql
🛠 TENTE VOCÊClique na tabela produtos › aba Explorar: devem aparecer 8 produtos com foto, preço, estoque e descrição.
⚠ ERRO COMUMEsquecer de importar e o site abrir com “Falha na conexão”: o PHP não acha o banco loja_turma.

Passo 4 — Abrir a vitrine e entender o fluxo

Acesse http://localhost/loja/index.php. A vitrine NÃO está escrita no HTML: o PHP consulta SELECT … FROM produtos WHERE destaque=1 e monta cada card na hora. Fluxo: navegador pede › Apache passa ao PHP › PHP consulta o MySQL › HTML volta pronto.

🛠 TENTE VOCÊNo phpMyAdmin, mude o preço do Mouse para 99,90 e atualize a página: o card muda sozinho. Isso é conteúdo dinâmico!
✔ CHECKSe apareceu o banner, o logo e os 4 cards com preço verde: seu ambiente está 100%.

Passo 5 — Detalhe do produto e pagamento

Clique num produto: a URL fica produto.php?id=1 — o id viaja por GET e o PHP busca a ficha completa (foto, descrição, estoque). Em “Ir para o pagamento”, escolha Pix, Cartão ou Boleto e confirme: o PHP grava a venda e baixa o estoque.

INSERT INTO vendas (produto_id, qtd, total) VALUES (1, 2, 179.80);
UPDATE produtos SET estoque = estoque - 2 WHERE id = 1;
🛠 TENTE VOCÊConfira no phpMyAdmin: linha nova em vendas e estoque diminuído em produtos. Depois abra o gerencial VB6 e veja o mesmo número!
⚠ ERRO COMUMPedir quantidade maior que o estoque: o site avisa “Estoque insuficiente” — validação no servidor funcionando.

Passo 6 — Testar no celular (mesmo Wi-Fi)

O celular não entende “localhost” (que é o PC). Descubra o IP do PC: Win+R › cmd › ipconfig (IPv4, ex.: 192.168.0.15). No celular, no mesmo Wi-Fi, abra http://192.168.0.15/loja/index.php. O layout se ajusta sozinho à tela.

🛠 TENTE VOCÊCompre um produto pelo celular e veja o estoque cair no PC: o banco é um só para todos os aparelhos.
⚠ ERRO COMUMCelular em 4G ou em outro Wi-Fi: não alcança o PC. Tem que ser a mesma rede.

Passo 7 — Backup e o desastre didático

Backup é cópia de segurança. No cmd: mysqldump -u root loja_turma > arquivo.sql. Restaurar: mysql -u root loja_turma < arquivo.sql. Professor(a): faça o desastre didático — DELETE FROM produtos; sem WHERE — e deixe a turma recuperar. Ninguém mais esquece.

mysqldump -u root loja_turma > C:\lp2\backups\loja_aula.sql
mysql -u root -e "CREATE DATABASE loja_teste;"
mysql -u root loja_teste < C:\lp2\backups\loja_aula.sql
mysql -u root loja_teste -e "SELECT COUNT(*) FROM produtos;"
✔ CHECKValidação pós-restauro: 4 tabelas e 8 produtos conferidos ANTES de confiar.

Passo 8 — O gerencial VB6 no mesmo banco

No VB6: crie um projeto Standard EXE, marque em Projeto › Referências a Microsoft ActiveX Data Objects 2.8, importe mdlConexao.bas e mdlRelatorios.bas e monte o formulário seguindo o arquivo frmGerencial_codigo.txt. O botão Atualizar lista mostra os mesmos produtos do site.

🛠 TENTE VOCÊCadastre um produto pelo VB6 e atualize o site: ele aparece na vitrine. Depois imprima o Relatório (ou “Microsoft Print to PDF”).
⚠ ERRO COMUM“Data source name not found”: falta o driver MySQL ODBC instalado no Windows.

Passo 9 — Missão do aluno: a SUA loja

Com o modelo dominado, cada aluno/dupla cria a própria loja (petshop, lanchonete, boutique, oficina…) repetindo a estrutura: 4+ páginas, 1 tabela nova com seed próprio, formulário com validação, página de detalhe com “pagamento”, e backup executado.

✔ CHECKRubrica sugerida (10 pts): site sem erros 2 · formulários validados 2 · consulta SQL exibindo dados 2 · tabela própria com seed 1,5 · pedido baixando estoque 1,5 · backup comprovado 1.
🛠 TENTE VOCÊTroque o CSS de cores (2 linhas no estilo.css) para a identidade da sua loja: mesma estrutura, cara nova.
